Folder 1 : Linux_MacOS ::

  File 1.: BubbleShooter_linux_macos_with_enter.c ::
  
  (Works Only On Linux & MacOS)
  
   This is the OLDER VERSION of the Bubble Shooter Game I made.
   In this version you will have to write the commands and then press enter key on your keyboad to submit the commands.

  NOTE: You can type multiple commands at once and run them.
        The remaining game is same.
  
  File 2. linux_macos_without_enter.c ::

  (Works Only On Linux & MacOS)
  
   This is the LATEST VERSION of the Bubble Shooter Game I made.
   In this version you will have to press the keys and the commands would be immediately executed and there is NO need to press enter key on your keyboad to submit the commands.
    
  NOTE: You cannot type multiple commands at once and run them.
        The remaining game is same.
